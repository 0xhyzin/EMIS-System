# نظام إدارة بيانات الموظفين (EMIS Data Manager)

تطبيق ويب حديث ومتطور لإدارة واستخراج بيانات الموظفين والقوة الأساسية والمنتدبين من نظام وزارة التربية والتعليم (EMIS)، وتصديرها بصيغة ملفات Word منسقة وشاملة.

## 🌟 المميزات
- 🔐 **مزامنة التوكينات:** ربط التوكينات واستخراج بيانات المدرسة والإدارة والمحافظة تلقائياً.
- 🏫 **القوة الأساسية والمنتدبين:** دعم جلب وفلترة القوة الأساسية والمنتدبين مع منع تكرار البيانات.
- 📊 **بناء جدول مخصص:** تحديد الأعمدة المطلوبة ودعم دمج الأعمدة (مثل الاسم بالكامل، المؤهل وتاريخه).
- 🔍 **بحث ذكي:** بحث متقدم بالاسم (تطبيع الحروف العربية) أو الكود أو الرقم القومي.
- 📑 **إصدار الصحيفة:** استدعاء وتحميل صحيفة الأحوال بنقرة زر واحدة.
- 📄 **تصدير Word محترف:** تصدير الجداول بتنسيقات ورقية (طولي/عرضي) وأرقام عربية/إنجليزي وتصميم RTL متكامل.
- 🎨 **واجهة عصرية:** تصميم Glassmorphic dark mode يدعم التجاوب والنسخ المباشر للبيانات.

## 🚀 تشغيل المشروع محلياً
```bash
npm install
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
