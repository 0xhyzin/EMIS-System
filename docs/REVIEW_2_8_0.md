# مراجعة الإصدار 2.8.0

تمت مراجعة الواجهة والخادم وقاعدة البيانات وربط الوزارة والمزامنة وإدارة الموظفين والقوائم والقوالب والمساعد وبيانات البريد والتصدير، باستخدام بيانات تجريبية ومجلدات مؤقتة منفصلة عن قاعدة المدرسة.

## التصدير المطلوب

من «الكشوف والتصدير»، جهّز الجدول واضبط الأعمدة والعناوين والحقول المدمجة، ثم اختر «صيغة الملف»: Word (.docx) أو Excel (.xlsx)، واضغط زر التحميل. الصيغتان تستخدمان نفس الأشخاص والبحث والفلترة والترتيب والقائمة المخصصة والتوقيعات.

تتذكر الواجهة الصيغة المختارة، وتُحفظ الصيغة واتجاه الورقة وشكل الأرقام مع قوالب الكشف. يوجد الاختيار أيضًا في المساعد؛ ويمكن تحديد الصيغة في نص الطلب. لتصدير الجدول الذي جهزته يدويًا بكل تفاصيله، استخدم زر التحميل في «الكشوف والتصدير».

ملف Excel عربي من اليمين لليسار، قابل للتعديل، مع ترويسة المدرسة والشعار والتوقيعات وتثبيت رأس الجدول والتصفية داخل Excel. تُحفظ الأرقام القومية وأرقام الهاتف والأكواد كنص لحماية الأصفار الأولى. التواريخ المنفصلة قابلة للترتيب كتاريخ، والحقول المدمجة تبقى بأسطرها داخل الخلية. البيانات التي تبدأ بعلامة معادلة تُحفظ كنص.

نموذج الحصة محفوظ أيضًا: اثنا عشر صفًا لكل صفحة Word أو ورقة Excel، مع التوقيعات وبيانات المعلم المحفوظة لهذا النموذج. زيادة العدد تُنشئ صفحات أو أوراقًا إضافية.

## ما تم إصلاحه أثناء المراجعة

- توحيد كود المشروع مع آخر نسخة مكتملة قبل إضافة الميزة، لأن مجلد العمل كان يحتوي كودًا أقدم من نسخة التسليم السابقة. تم الاحتفاظ بملفات بيانات المدرسة.
- إتاحة الهاتف الأرضي والحقول الإضافية والسجلات اللاحقة للمؤهلات والوظائف داخل اختيار الأعمدة والفلترة والترتيب والمساعد. البيانات الإضافية تُختار بالاسم بدل موضعها في قائمة الموظف.
- حفظ اتجاه الورقة وشكل الأرقام وصيغة التصدير مع القالب، مع ترقية القوالب القديمة تلقائيًا إلى إعدادات افتراضية سليمة.
- منع النقر المتكرر أثناء التصدير، وإعادة إتاحة الزر والاختيارات بعد الفشل. تحسين عرض التنقل والاختيارات من الهاتف.
- تحسين قراءة الأرقام والتواريخ في خلايا Word الضيقة، وتوسيع ارتفاع العناوين والتوقيعات عند الحاجة في جداول Excel ذات العمود أو العمودين.
- منع اعتبار رد الوزارة ذي الحالة HTTP 200 والخطأ الداخلي مزامنة ناجحة بقائمة فارغة.
- منع حفظ تعديل لا يغيّر البيانات فعليًا كاستثناء محلي يوقف تحديث الموظف بالمزامنة.
- إصلاح طلب تأكيد تعديل البريد من المساعد ليتوافق مع خدمة البريد المشتركة، ومنع إعادة توجيه الطلبات التي تحمل بيانات الاتصال إلى عنوان آخر.
- تحديث الاعتماديات ومعالجة مشكلات الحزم التي ظهرت في تدقيق npm.

## التحقق وحدوده

نجحت 201 حالة اختبار في 23 مجموعة، تشمل قاعدة البيانات والإضافة والتعديل والحذف والجلسات والمزامنة والقوائم والبريد والمساعد والصيغتين والقوالب والحقول الإضافية ونموذج الحصة.

اختُبر تنزيل Word وExcel فعليًا من Chromium على الكمبيوتر، وتنزيل Excel من واجهة الهاتف بعرض 390 بكسل. اختُبر جدول مخصص بقائمة أشخاص وفلترة وترتيب وعناوين معدلة وحقول إضافية، وتأكدت مطابقة بيانات الصيغتين واسترجاع إعدادات القالب بعد تغييره وإعادة تحميل الصفحة. لم تظهر أخطاء JavaScript أو تمرير أفقي للصفحة.

تم فتح الملفات الناتجة وإعادة قراءتها للتحقق من القيم والتواريخ والأصفار، ومراجعة كل صفحات Word ونموذج الحصة وطبعات Excel بصريًا. التدقيق `npm audit --omit=dev` لم يظهر ثغرات معروفة وقت هذه المراجعة.

اختبارات الوزارة والبريد والمساعد تستخدم ردودًا ومزوّدًا تجريبيًا؛ لم تُنفذ مزامنة فعلية أو تغييرات في حساب الوزارة أو اتصال Groq بمفتاحك. استخدام الخدمات الفعلية يتطلب جلسة الوزارة أو مفتاح المساعد الصالحين.

## تشغيل التحديث

أوقف البرنامج القديم، ثم نفّذ من مجلد المشروع:

```sh
npm ci
npm start
```

افتح `http://localhost:3000` وحدّث الصفحة باستخدام `Ctrl+Shift+R`. يجب أن يظهر الإصدار 2.8.0. للهاتف، استخدم `npm run start:lan` واربط الجهاز بالرمز من صفحة الإعدادات على الكمبيوتر. اترك الكمبيوتر يعمل أثناء الاستخدام. لا تمسح مجلد `data` عند التحديث.
