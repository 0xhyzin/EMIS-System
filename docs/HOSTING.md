# التشغيل الكامل على Vercel

الإصدار 2.10.0 يفصل بوابة الموقع عن خدمة المدرسة. الواجهة ودالة البوابة على Vercel، وخدمة Node وChromium وLibreOffice داخل Sandbox مسمى. ملفات SQLite والجلسات والشعار داخل Drive دائم؛ لا تعتمد النسخة السحابية على تشغيل الكمبيوتر.

## الدخول والاستخدام

1. افتح رابط الموقع وأدخل كلمة مرور المدرسة الخاصة. تُحفظ جلسة الجهاز 30 يومًا.
2. افتح «الربط والإعدادات» ثم «تسجيل الدخول بـ Microsoft». تظهر نافذة الموقع الرسمي داخل البرنامج. اضغط الخانة داخل الصورة واستخدم حقل الكتابة أسفلها لإرسال النص. فعّل إخفاء النص عند كتابة كلمة المرور.
3. أكمل تحقق Microsoft بنفسك، واختر المدرسة ثم افتح قائمة العاملين في موقع الوزارة. لا يعرض البرنامج «متصل بالوزارة» قبل استجابة ناجحة من خدمة العاملين الفعلية.
4. استخدم المزامنة العادية للاحتفاظ بالإضافات والتعديلات اليدوية. تصدير Word وExcel وPDF يعمل على الاستضافة نفسها.

إغلاق نافذة الوزارة يحتفظ بملف المتصفح. تسجيل الخروج يفصل الجهاز الحالي فقط. «فصل حساب الوزارة» يمسح ربط الوزارة ويلغي جلسات الأجهزة. للأجهزة الإضافية ينشئ المالك رابط ربط ورمزًا صالحين خمس دقائق؛ افتح الرابط على الجهاز الجديد ثم أدخل الرمز. الجهاز المرتبط يستطيع إدارة السجلات والكشوف، بينما ربط الوزارة وإدارة مفتاح المساعد للمالك.

قد تطلب الوزارة أو Microsoft إعادة التحقق عند انتهاء الجلسة. الوصول للموقع الرسمي من شبكة الاستضافة شرط للربط والمزامنة؛ وجود المتصفح وحده لا يثبت إمكانية الاتصال أو قبول حساب المدرسة.

## تجهيز الموارد

بعد ربط Vercel CLI بالمشروع وسحب OIDC للتطوير، شغّل:

```sh
npm ci
vercel env pull .env.local
node --env-file=.env.local scripts/provision-cloud.js
```

ينشئ السكربت Sandbox وDrive وملفات إعداد خاصة داخل `work/cloud-deploy/`، ويثبت Chromium وLibreOffice وخطوط العربية. لا ترفع هذا المجلد أو `.env.local` أو بيانات المدرسة إلى GitHub. لا تعِد إنشاء كلمة المرور أو أسرار الجلسات أثناء التحديث، لأن تغييرها يلغي الجلسات الحالية.

اضبط المتغيرات التالية في Vercel، في بيئتي الإنتاج والمعاينة:

- `EMIS_CLOUD=true`
- `EMIS_SANDBOX_NAME`: اسم Sandbox المجهز.
- `APP_ORIGIN`: أصل HTTPS العام للموقع، دون مسار.
- `EMIS_PREVIEW_ORIGIN`: أصل معاينة ثابت موثوق، إن لزم.
- `EMIS_OWNER_PASSWORD_HASH`: تجزئة scrypt من ملف الإعداد الخاص.
- `EMIS_SESSION_SECRET` و`EMIS_PROXY_SECRET`: أسرار مستقلة بطول 32 حرفًا أو أكثر.

يستخدم SDK رمز OIDC الحالي لكل طلب؛ لا تضف رمز التطوير المؤقت إلى إعداد الإنتاج. البوابة تمرر رمز التشغيل داخليًا لتستطيع الخدمة النوم بعد خمس دقائق من عدم النشاط. طلبات الحالة وحدها لا تؤخر النوم. إعادة الفتح قد تستغرق وقتًا لتشغيل الخدمة.

## البيانات والحماية

قاعدة المدرسة على `/data/emis/school.db`، مع مخزن الجلسات المشفر وملف متصفح الوزارة في المجلد نفسه. لا تُنسخ جلسات الوزارة أو مفاتيح الكمبيوتر تلقائيًا عند نقل البيانات؛ يسجل المالك دخوله للوزارة على الاستضافة. استخدم SQLite online backup عند أخذ نسخة من قاعدة تعمل، وتوقف خدمة الاستضافة قبل استبدال القاعدة. احتفظ بالنسخة المحلية الأصلية والنسخة الاحتياطية.

عنوان Sandbox المباشر يرفض كل طلب دون سر البوابة. لا تُعرض منافذ التحكم في Chromium. صفحة الموقع وطلب الإصدار متاحان دون تشغيل Sandbox؛ قراءة بيانات العاملين تحتاج جلسة موقعة وصالحة في مخزن الجلسات. محاولات كلمة المرور الخاطئة تُرفض قبل تشغيل الموارد. ملفات الإعداد والمخرجات وبيانات المدرسة مستبعدة من النشر.

`GET /api/deployment/status` بعد تسجيل الدخول يعرض جاهزية التخزين والمتصفح وPDF. عند غياب إعداد السحابة تعرض البوابة صفحة التجهيز وتعيد واجهات البيانات 503. لا تُنشئ قاعدة مؤقتة في Vercel Function.

## الخطة المجانية

Hobby يتضمن 5 ساعات CPU نشطة و420 GB-hours ذاكرة شهريًا؛ جلسة Sandbox الواحدة حتى 45 دقيقة. بعد الوصول للحد يتوقف إنشاء الجلسات إلى دورة الاستخدام التالية، دون رسوم إضافية على Hobby. تبدأ جلسة جديدة عند الطلب بعد انتهاء الجلسة السابقة؛ البيانات محفوظة في Drive. لا تعني الخطة تشغيلًا متواصلًا طوال الشهر، ومشاركة الموقع بكثافة تستهلك الحصة المشتركة للمشروع.

هذه الحدود وفق [تسعير Vercel Sandbox](https://vercel.com/docs/sandbox/pricing). تفاصيل [البيانات الدائمة](https://vercel.com/docs/sandbox/concepts/persistent-sandboxes) و[Drives](https://vercel.com/docs/sandbox/concepts/drives).

## التحقق قبل نشر الإنتاج

اختبر الدخول ورفض الوصول العام، والإضافة والحذف، والصيغ الثلاث، ثم توقف Sandbox وأعد تشغيله للتحقق من استمرار السجل والجلسة. اختبر متصفح الوزارة على الاستضافة الفعلية؛ نجاح الاختبارات التجريبية لا يؤكد اتصال الشبكة أو دخول حسابك الفعلي. لا تُجرِ المزامنة الكاملة أثناء النقل لأنها تحذف الإضافات والتعديلات اليدوية.
