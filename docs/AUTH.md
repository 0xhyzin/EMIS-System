# تسجيل الدخول وربط الهاتف

## طريقة الاستخدام

1. شغّل البرنامج على الكمبيوتر وافتحه من `http://localhost:3000` أو `http://127.0.0.1:3000`.
2. اضغط **تسجيل الدخول بحساب Microsoft**. سيفتح البرنامج نافذة مستقلة من Chrome أو Edge أو Chromium على **موقع الوزارة الرسمي**، ثم يستخدم زر Microsoft الموجود بالموقع.
3. أدخل حساب الوزارة في صفحة Microsoft نفسها، وأكمل أي تحقق يطلبه حسابك. اختر المدرسة إن طُلب منك، ثم افتح **قائمة العاملين** في موقع الوزارة.
4. عندما يعرض البرنامج «تم الاتصال»، يمكنك الرجوع إليه والمزامنة. لا توجد خطوة نسخ توكنات.

يحتاج الكمبيوتر إلى واجهة سطح مكتب، ومتصفح مثبت من Chrome أو Edge أو Chromium، وNode.js 22.13 أو أحدث. لا يحتاج هذا الأسلوب إلى تسجيل تطبيق جديد في Microsoft Entra. يمكن تعيين `EMIS_BROWSER_PATH` إلى المسار الكامل للمتصفح إذا لم يُكتشف تلقائيًا. لا تُستخدم ملفات المتصفح الشخصي الحالية؛ ينشئ البرنامج ملفًا مستقلًا لهذا الاتصال.

## ما الذي يُحفظ؟

- تبقى بيانات المدرسة المحلية متاحة على الكمبيوتر حتى عند انقطاع الإنترنت أو انتهاء اتصال الوزارة.
- يُحفظ ملف متصفح الوزارة داخل `data/ministry-browser`، لذلك يمكن للوزارة وMicrosoft إعادة استخدام الدخول السابق وفق سياسة الحساب.
- لا يُعتبر تسجيل Microsoft وحده دليلًا على الوصول إلى بيانات المدرسة. يُعلَن الاتصال بعد نجاح طلب فعلي لقائمة العاملين أو بيانات العاملين إلى `https://professopi.emis.gov.eg` ومعه معلومات المدرسة وتوكنات غير منتهية.
- تُحفظ بيانات اتصال الوزارة مشفرة بخوارزمية AES-256-GCM في `data/auth.sqlite`؛ مفتاح التشفير في `data/auth.key` بصلاحية محلية محدودة. حافظ على مجلد البيانات ونسخه الاحتياطية كبيانات خاصة، فالمفتاح على الكمبيوتر نفسه.
- تحفظ أجهزة الهاتف المرتبطة جلسة لمدة **30 يومًا** في Cookie من نوع `HttpOnly` و`SameSite=Strict`، و`Secure` عند استخدام HTTPS. لا تُرسل توكنات الوزارة إلى واجهة البرنامج أو الهاتف، ولا تُخزَّن في `localStorage`.
- ملف SQLite يخزن بصمة رمز جلسة الهاتف، ولا يخزن رمزها الأصلي. رمز ربط الهاتف صالح لخمس دقائق ولمرة واحدة؛ إنشاء رمز جديد يلغي السابق.

لا يمكن ضمان بقاء حساب الوزارة مسجلًا للأبد: قد تنهي Microsoft أو الوزارة الجلسة، أو تطلب تحققًا إضافيًا، أو يغير المستخدم كلمة المرور. يتحقق البرنامج من صلاحية التوكنات قبل كل استخدام. إذا كانت نافذة الوزارة مفتوحة بالفعل، يجرب تحديثًا واحدًا محدودًا لإعادة الحصول على جلسة صالحة؛ وإلا يطلب تجديد الدخول من الكمبيوتر. لا يفتح الهاتف نافذة دخول مفاجئة على الكمبيوتر.

**تسجيل الخروج على الكمبيوتر** يمسح اتصال الوزارة وملف المتصفح المستقل ويلغي جلسات الهواتف ورموز الربط المعلقة، دون حذف بيانات العاملين. **تسجيل الخروج على الهاتف** يلغي جلسة ذلك الهاتف فقط. يظل فتح بيانات البرنامج من الكمبيوتر المحلي نفسه متاحًا؛ هذا تطبيق مدرسة محلي وليس نظام مستخدمين متعدد الصلاحيات.

إذا تعذر إغلاق نافذة الوزارة أو مسح ملفها، تُلغى بيانات اتصال البرنامج وجلسات الهواتف فورًا، ويظهر طلب بإغلاق نافذة الوزارة وإعادة تسجيل الخروج لإكمال المسح. لا يعيد البرنامج استخدام ملف المتصفح قبل نجاح هذه الخطوة، ولا تسمح ردود المتصفح المتأخرة باستعادة جلسة أُلغيَت.

## تشغيله من الهاتف على نفس الشبكة

الوضع الافتراضي يستمع إلى الكمبيوتر فقط، ولا يعرض بيانات المدرسة لأي جهاز على الشبكة. للوصول من هاتف، يجب تشغيل الخادم بعنوان معلوم ثم إنشاء رمز ربط من صفحة البرنامج على الكمبيوتر.

**الطريقة الأسهل:** اتصل بالهاتف والكمبيوتر بشبكة المنزل أو المدرسة نفسها، ثم شغّل من مجلد البرنامج:

```sh
npm run start:lan
```

يختار المشغّل عنوان IPv4 خاصًا للشبكة ويعرض رابط الهاتف ورابط الكمبيوتر. يعطي الأولوية لاتصال Ethernet ثم Wi-Fi، ويتجنب عناوين الإنترنت ومحولات VPN وDocker الافتراضية. عند وجود أكثر من شبكة يعرض الخيارات؛ يمكنك اختيار عنوان بعينه باستخدام `APP_ORIGIN`. فتح الوصول للشبكة يحدث فقط عند تشغيل هذا الأمر صراحةً؛ يظل `npm start` على الكمبيوتر فقط افتراضيًا. اضغط `Ctrl+C` لإيقاف الخادم وإغلاق اتصال المتصفح بطريقة سليمة.

يستخدم الأمر HTTP على شبكة موثوقة، ويطبع تنبيهًا بذلك. لو كانت شبكة المدرسة تمنع اتصال الأجهزة ببعضها، فلن يكفي وجودهما على اسم Wi-Fi نفسه؛ استخدم شبكة تسمح بالاتصال المحلي. لا تُعطل جدار الحماية بالكامل، ولا تُعد توجيه منفذ البرنامج إلى الإنترنت.

للإعداد اليدوي أو اختيار عنوان محدد:

المثال التالي لشبكة محلية موثوقة، حيث عنوان الكمبيوتر `192.168.1.20`. استبدله بعنوان جهازك الفعلي:

```sh
HOST=0.0.0.0 APP_ORIGIN=http://192.168.1.20:3000 ALLOW_INSECURE_LAN=true npm start
```

على PowerShell:

```powershell
$env:HOST = "0.0.0.0"
$env:APP_ORIGIN = "http://192.168.1.20:3000"
$env:ALLOW_INSECURE_LAN = "true"
npm start
```

ثم:

1. على الكمبيوتر افتح **localhost**، واضغط **الربط والإعدادات** ثم **إنشاء رمز ربط جهاز** لإظهار رمز الربط.
2. على الهاتف افتح عنوان `APP_ORIGIN`، وأدخل الرمز. يمنح الربط الهاتف الوصول إلى بيانات المدرسة والتعديل والتصدير.
3. اترك البرنامج والكمبيوتر يعملان أثناء استخدام الهاتف. إغلاق الخادم يوقف الوصول من الهاتف، لكنه لا يمسح البيانات أو الجلسات المحفوظة.

HTTP على الشبكة المحلية لا يشفر المرور بين الهاتف والكمبيوتر؛ لهذا يتطلب التفعيل الصريح السابق ويُستخدم على شبكة موثوقة فقط. HTTPS هو الاختيار المناسب عند إعداد عنوان دائم، ويعمل دون `ALLOW_INSECURE_LAN`. لا توجّه منفذ البرنامج إلى الإنترنت. عند استخدام reverse proxy يجب ضبط `APP_ORIGIN` على عنوان HTTPS والمحافظة على Host الأصلي وإرسال ترويسات forwarding؛ الطلبات الممررة عبر proxy لا تُعامل كمالك الكمبيوتر المحلي.

## حدود التحقق والتوافق

تم التحقق من صفحة الوزارة العامة وزر Microsoft في 20 سبتمبر 2026. التدفق المرصود يستخدم Authorization Code مع PKCE ويعود إلى `https://teacher.emis.gov.eg/complete`. يشغّل البرنامج هذا التدفق الأصلي في المتصفح، ولا يستبدله بطلب Microsoft Graph أو تطبيق Microsoft غير مرتبط بالوزارة. [صفحة الوزارة](https://teacher.emis.gov.eg/) و[توثيق Microsoft للتدفق](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow).

هذه وسيلة اتصال محلية عبر متصفح المستخدم، وليست API تسجيل دخول موثقة أو معتمدة من الوزارة. قد تحتاج تحديثًا إذا تغيّرت صفحة الوزارة أو ترويسات الخدمة. في النسخة الحالية يُلتقط الرد الناجح للمسارات الثلاثة المعروفة `GetEmployeeByEmpFlag` و`EmployeesNadb` و`GetEmployeeFullData` فقط، وتُرفض النطاقات الأخرى والتوكنات المنتهية وردود الخطأ حتى لو حملت HTTP 200. يجب أن تطابق ترويسات المدرسة والإدارة ونوع المستخدم بيانات UT. ويرفض الاتصال التبديل إلى مدرسة أو إدارة مختلفة عن الاتصال المحفوظ حتى فصل الحساب أولًا. في حسابات الجهات المتعددة، يجب أن تطابق المدرسة المختارة بيانات المدرسة التي يحددها UT؛ خلاف ذلك لن يُعلن البرنامج نجاح الاتصال.

لا تُختبر حسابات المستخدمين أو كلمات مرورهم تلقائيًا. اختبارات المشروع تستخدم بيانات اصطناعية ومجلدات مؤقتة، وتتحقق من انتهاء الصلاحية والتشفير واستمرار الجلسة وإلغائها وتقييد العناوين وربط الهاتف ورفض ردود الخدمة غير الصالحة. **التحقق الكامل من المزامنة الحية يتطلب إتمام المستخدم تسجيل الدخول بحسابه الفعلي ثم تنفيذ مزامنة.**

## عقد التكامل للمطور

- `GET /api/auth/status`: حالة محلية أو جلسة هاتف. قبل الربط لا يعرض معلومات المدرسة أو حالة اتصالها.
- `POST /api/auth/microsoft/start`: من الكمبيوتر المحلي فقط؛ يفتح نافذة الموقع الرسمي ويعيد الحالة `waiting` حتى تأكيد اتصال الوزارة.
- `POST /api/auth/pairing/start`: من الكمبيوتر المحلي؛ يعيد `code` و`expiresAt` و`phoneUrl`.
- `POST /api/auth/pairing/complete`: `{ "code": "12345678" }`؛ يستهلك رمزًا صالحًا ويثبت Cookie لجلسة الهاتف.
- `POST /api/auth/logout`: إلغاء الجلسة؛ من الكمبيوتر يفصل الوزارة ويلغي الأجهزة المرتبطة.
- `POST /api/auth/microsoft/disconnect`: فصل الوزارة وإلغاء الأجهزة المرتبطة من الكمبيوتر.
- `createAuth({ dataDir })` يعيد `router` و`requireAccess` و`requireSameOrigin` و`getMinistryCredentials()` و`invalidateMinistryCredentials()` و`close()`.
- يجب حماية كل بيانات العاملين والتصدير والإعدادات بـ`requireAccess` و`requireSameOrigin`. يُثبَّت `router` على `/api/auth`، وهو يطبّق فحص المصدر على مساراته.
- عند رد الوزارة 401 أو 403، يستدعي موصل الوزارة `invalidateMinistryCredentials()`؛ يبقى العمل على البيانات المحلية متاحًا.
- يمنع فحص المضيف والـOrigin الوصول عبر DNS rebinding أو طلبات المواقع الأخرى. لا تفعل CORS عامًّا ولا تثق في `X-Forwarded-*` لمنح وصول محلي.

لا تنقل `auth.key` أو `auth.sqlite` أو `ministry-browser` ضمن نسخة البرنامج التي تشاركها مع شخص آخر. عند تغيير المدرسة، استخدم مجلد بيانات مستقلًا لتجنب خلط السجلات.
